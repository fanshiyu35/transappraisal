AppraisalStudio

The platform for transit and road investment appraisal — from project templates to board-ready results.

AppraisalStudio supports the full appraisal workflow: project templates, cost and benefit modelling, scenario comparison, and reporting in the formats European appraisal frameworks expect. Version 4.2 added new data import profiles for European appraisal frameworks and usability improvements to the scenario comparison view.

Project Appraisal module

The Project Appraisal module carries conventional benefit-cost analysis and the staged-delay extension described below. Modules are enabled under the terms of each customer's licence agreement.

Staged-Delay BCA module (SDI-BCA)

The Staged-Delay BCA module implements the Staged-Delay-Inclusive Benefit-Cost Analysis (SDI-BCA) method, licensed from the University of California, Irvine and Ms. Yanxi Liu (Agreement UCI-OTA-2025-017, 20 June 2025). SDI-BCA extends conventional benefit-cost analysis by modelling implementation stages and the delays that propagate between them, so that a delayed stage's effect on downstream stages, on net present value and on the benefit-cost ratio is reported explicitly.

  • Implements the procedure defined in Research Report No. 231, National Transport Research Programme (June 2025).
  • Stage dependency graphs are defined per project template; delays propagate automatically to dependent stages with fractional-year pro-rating.
  • Outputs include the stage-level marginal decomposition of the change in net present value and the benefit-cost ratio, with interaction terms reported separately.
  • Available in the Project Appraisal module under the terms of each customer's licence agreement.

The module was introduced in AppraisalStudio version 4.2 (September 2025).
